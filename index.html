Optimistic vs Onchain

Confirmation Mode vs Replay Mode

Balancing execution speed with cryptographically enforced fallback adjudication.

MODE 01 Confirmation Mode

• The standard optimistic execution pipeline
• Offchain execution: Fast and cost-efficient
• Onchain receipts: Cryptographic commitments posted
• Dispute fallback: Disputed steps replayed

MODE 02 Replay Mode

• Heavyweight deterministic onchain execution
• Full onchain runtime: Executes directly on Fogo
• Adjudication engine: Resolves disputed claims
• Credible enforcement: Keeps executors honest
